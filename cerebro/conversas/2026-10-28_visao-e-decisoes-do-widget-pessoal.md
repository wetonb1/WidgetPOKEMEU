- Widget só dele para Windows 10, feito pelo Claude Code no VS Code com prompts prontos; leve, inicia com o PC e dá boas-vindas do Pokémon ("olá, meu mestre").
- Infos do sistema, música, atalhos de apps/sites, terminal (cmd) embutido para o Claude; pets são Pokémon escolhidos por ele.
- Versão para iPhone seria outro projeto.
- Cérebro: resumos .md de conversas com IAs, cabeçalho de até 2 linhas de palavras-chave; skills para ler cabeçalhos, compactar e buscar por título.
- Widget controla agentes do Antigravity (abrir, escolher chat do projeto, consultar o cérebro) e troca de conta quando acabarem os tokens.
- Aba de skills com instalação fácil para Claude e Antigravity e gráfico de custo em tokens.
- Decisão: cérebro primeiro só com Claude Code; Antigravity depois.
